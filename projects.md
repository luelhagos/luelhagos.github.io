## Natural Language Processing Projects

### Tigrinya GPT-2 Model

I have trained a GPT-2 model from scratch for Tigrinya (ትግርኛ) text generation. The project involved:

- Collection of approximately 21 million tokens primarily from news sources (90%+)
- Training a medium-sized architecture with 51.9 million parameters
- Implementation of a 128 tokens context window
- Development of a public demo for testing the model's capabilities

The model shows promising results in generating coherent Tigrinya text, representing a significant contribution to NLP resources for lower-resource languages.
